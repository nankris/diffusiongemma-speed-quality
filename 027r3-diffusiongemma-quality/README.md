# Experiment 027 round 3: paired GSM8K quality

Preregistered before allocation/inference, 2026-10-16 UTC.
Hypothesis: DiffusionGemma 26B-A4B Q4_K_M is more accurate than autoregressive Gemma 4 26B-A4B Q4_K_M with identical prompts and thinking disabled.

Design: 300 distinct public GSM8K test items in retained seed-27 order (first 300 in scripts/prompts.json). One answer per model/item, no selection based on outcomes. Empty thought channel in byte-identical rendered prompts; 4096 output tokens, context 8192, eight CPU expert layers for both on one L4. Pinned llama.cpp 6a7388aac74ab896d9d4f0fb187ddac4847c02f0. DG native entropy-bound sampling, AR greedy; this compares deployed model/decoder combinations. Both artifacts are vendor Q4_K_M (AR filename includes UD). Record artifact revisions and sizes. Answer extraction: last explicit Answer: numeric value, else last numeric value; normalize commas and compare exact decimal to gold; absent/unparseable is wrong. No grader model.

Different from earlier rounds: fixed n=300, one inferential look, explicit equivalence test, resumable per-answer persistence, synchronous local download after each batch of at most 25 answers, plus periodic snapshots. No scored artifacts from earlier rounds are reused. Raw answers are retained even if setup, inference, or runtime fails. DG persistent input loop saves each turn independently; AR raw completion server disables prompt caching. Patch only disables extra chat rendering and adds independent prompt input/output/timing.

Fixed decision rule: let delta=DG accuracy minus AR accuracy. Exact two-sided McNemar p<.05 with delta>0 yields PROVEN (superiority); delta<0 yields DISPROVEN (inferiority). Otherwise perform paired TOST at alpha=.05 with bounds [-.05,+.05], using paired differences {-1,0,1} and Student-t standard error: a 90% CI wholly within the margin yields DISPROVEN (equivalent within five percentage points). Five points means at most 15 net answers per 300: smaller differences are not practically decisive for this pilot deployment comparison. Superiority takes precedence if both tests pass. Report paired 95% CI, Wilson accuracy CIs, discordant counts, both TOST p-values, and throughput. No interim testing or optional sample stopping. If neither test resolves the result, report statistical uncertainty honestly; a complete n=300 study cannot logically guarantee a binary verdict. STILL INCONCLUSIVE reserved for exhausted compute/wall budget, including inability to collect further evidence within these caps.

Quick prospective power: paired variance approximately q-delta², where q is discordance. At n=300, q=.10 and true delta=0, SE=.01826; normal TOST power is 2*Phi(.05/SE-1.645)-1 ≈ .726. At q=.15 power ≈ .446. For delta=.08, q=.15, normal two-sided superiority power ≈ .955. n≈343 gives 80% equivalence power at q=.10; requested n=300 is slightly smaller. Thus 300 likely resolves equality when disagreement is low or a substantial advantage, but no honest power calculation guarantees resolution near the decision boundaries.
